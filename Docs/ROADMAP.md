# INDIAN FIRE — Development roadmap

1. **Local vertical slice:** movement, camera, INDIAN FIRE India-inspired world map, health, safe-zone prototype.
2. **Combat loop:** server-validated weapon firing, reloads, ammo, pickups, hit feedback.
3. **Android UX:** joystick, look drag, fire/reload/jump/crouch buttons, graphics settings.
4. **Online rooms:** authentication, matchmaking, lobby, party invites, reconnect handling.
5. **Authoritative matches:** dedicated server owns player state, hit validation, loot, zone and winner.
6. **Scale:** load-test increasing room sizes (e.g. 8, 16, 32, then 50); optimize bandwidth and server tick rate.
7. **Release readiness:** privacy/safety controls, reporting, moderation, crash analytics, device testing.

## Fair-play testing
Any aim-assist or ESP-like experiments must stay inside a private development build and use test bots or debug entities. Never attach the tools to third-party games or public matches.
